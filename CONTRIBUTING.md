# Contributing to ArtQTML (local_artqtml)

## How to report a problem or idea

Use the public GitHub Issues tracker:

https://github.com/akoharek/moodle-local_artqtml/issues

1. Open **New issue**.
2. Pick a template:
   - **Bug report** — something broken or unexpected
   - **Feature request** — enhancement or new capability
   - **Other / code issue** — docs, packaging, clarifications, etc.
3. Fill in Moodle version and steps where asked.
4. Never paste API keys, tokens, or personal data.

Labels such as `bug`, `enhancement`, and `question` help triage; templates apply them automatically when possible.

## Pull requests

PRs against `main` are welcome for clear bug fixes and documentation. Keep changes focused; match existing Moodle coding style in this plugin.

Before pushing, run `bash tools/check.sh` locally (see `tools/TOOLCHAIN.md`).
